A study group is a shared space for a class, a course or a few friends. Members share quizzes and notes, and an activity feed shows what everyone has been doing.

## Create a group

1. Open **Study Groups** and choose **Create Group**.
2. Give it a name and, optionally, a description of what the group is about.
3. Choose **Create**. You are the group's owner.

## Invite people

Every group has an invite code. Open the group, use **Copy invite code**, and send it to the people you want in.

If a code has been shared somewhere it shouldn't have been, **Regenerate invite code** makes a new one. The old code stops working straight away, and people already in the group stay in.

## Join a group

1. Open **Study Groups**.
2. Paste the invite code you were given into the invite code box.
3. Choose **Join Group**.

## Share with the group

- **Share a quiz** so everyone can play it. You keep ownership, and the answer key is still never sent to anyone else's browser.
- **Share a note** so everyone can read it. Shared notes are read-only: members can study from them, but only you can edit.
- **Save a copy** of a shared quiz to your own Quizzes, when the owner has allowed copying.

You can remove something you shared at any time. Owners and admins can remove anything shared in the group.

<Note>
  Nobody sees your quiz scores unless you share them.
</Note>

## Roles

| | Member | Admin | Owner |
| --- | :---: | :---: | :---: |
| Play shared quizzes and read shared notes | ✓ | ✓ | ✓ |
| Share and remove your own quizzes and notes | ✓ | ✓ | ✓ |
| Remove anything shared in the group | | ✓ | ✓ |
| Edit the group's name and description | | ✓ | ✓ |
| Regenerate the invite code | | ✓ | ✓ |
| Remove members | | Members only | Anyone |
| Make someone an admin, or a member again | | | ✓ |
| Allow members to save copies of shared quizzes | | | ✓ |
| Delete the group | | | ✓ |

Nobody can change their own role, and there is only ever one owner.

## Leave or delete a group

- **Leave** from the group page. You lose access to its shared quizzes and activity. Anything you shared stays with the group until you or an admin removes it.
- **The owner cannot leave**, because the group would have nobody able to manage it. The owner can delete it instead. Deleting a group is permanent and cannot be undone.

If an owner deletes their Clamly account, their groups are deleted with it.
