Un groupe d'étude est un espace commun pour une classe, un cours ou quelques amis. Les membres partagent des quiz et des notes, et un fil d'activité montre ce que chacun a fait.

## Créer un groupe

1. Ouvre **Study Groups** et choisis **Create Group**.
2. Donne-lui un nom et, si tu veux, une description de ce dont parle le groupe.
3. Choisis **Create**. Tu es le propriétaire du groupe.

## Inviter des gens

Chaque groupe a un code d'invitation. Ouvre le groupe, utilise **Copy invite code** et envoie-le aux personnes que tu veux inviter.

Si un code s'est retrouvé là où il ne devait pas, **Regenerate invite code** en crée un nouveau. L'ancien code cesse de fonctionner immédiatement, et les membres déjà présents restent dans le groupe.

## Rejoindre un groupe

1. Ouvre **Study Groups**.
2. Colle le code d'invitation reçu dans le champ prévu.
3. Choisis **Join Group**.

## Partager avec le groupe

- **Partage un quiz** pour que tout le monde puisse y jouer. Il reste à toi, et les bonnes réponses ne sont toujours jamais envoyées au navigateur des autres.
- **Partage une note** pour que tout le monde puisse la lire. Les notes partagées sont en lecture seule : les membres peuvent réviser avec, mais toi seul peux les modifier.
- **Save a copy** enregistre un quiz partagé dans tes propres Quizzes, si le propriétaire a autorisé les copies.

Tu peux retirer à tout moment ce que tu as partagé. Le propriétaire et les admins peuvent retirer tout ce qui est partagé dans le groupe.

<Note>
  Personne ne voit tes scores aux quiz, sauf si tu les partages.
</Note>

## Rôles

| | Membre | Admin | Propriétaire |
| --- | :---: | :---: | :---: |
| Jouer aux quiz partagés et lire les notes partagées | ✓ | ✓ | ✓ |
| Partager et retirer ses propres quiz et notes | ✓ | ✓ | ✓ |
| Retirer tout ce qui est partagé dans le groupe | | ✓ | ✓ |
| Modifier le nom et la description du groupe | | ✓ | ✓ |
| Régénérer le code d'invitation | | ✓ | ✓ |
| Retirer des membres | | Membres seulement | Tout le monde |
| Nommer quelqu'un admin, ou le repasser membre | | | ✓ |
| Autoriser les membres à copier les quiz partagés | | | ✓ |
| Supprimer le groupe | | | ✓ |

Personne ne peut changer son propre rôle, et il n'y a toujours qu'un seul propriétaire.

## Quitter ou supprimer un groupe

- **Quitte** le groupe depuis sa page. Tu perds l'accès à ses quiz partagés et à son activité. Ce que tu as partagé reste dans le groupe jusqu'à ce que toi ou un admin le retire.
- **Le propriétaire ne peut pas quitter le groupe**, sinon plus personne ne pourrait le gérer. Il peut le supprimer à la place. La suppression d'un groupe est définitive et ne peut pas être annulée.

Si un propriétaire supprime son compte Clamly, ses groupes sont supprimés avec lui.
