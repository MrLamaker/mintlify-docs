Every note opens as its own full page. It saves as you type, and it is stored as Markdown, so you can export it and open it anywhere.

## Write and format

Start typing on an empty line, or open the insert menu that appears there to add a block. Select any text to format it or to use AI on it.

<AccordionGroup>
  <Accordion title="Blocks you can add or turn text into">
    Text, Heading 1 to 4, bulleted list, numbered list, to-do list, toggle list, quote, code block, callout, divider, and **Side by side**, which splits the page into two columns.
  </Accordion>
  <Accordion title="Study callouts">
    Callouts are boxes for the things you will want to find again before an exam. Each one has a type: **Definition** (the default), **Exam tip**, **Warning** or **Formula**.
  </Accordion>
  <Accordion title="Text formatting">
    Bold, italic, underline, strikethrough, inline code and links, plus highlights in yellow, green, blue, pink, purple and coral.
  </Accordion>
</AccordionGroup>

## AI writing help

Select some text and switch the toolbar to AI. Pick an action, and the result appears in a review card underneath. **Your note does not change until you choose.**

| Action | What it does |
| --- | --- |
| **Improve writing** | Clearer, tighter wording that keeps your meaning |
| **Fix spelling & grammar** | Corrections only |
| **Make shorter** / **Make longer** | Condenses or expands |
| **Simplify language** | Plainer words for dense material |
| **Summarize** | The main points of the selection |
| **Explain this** | An explanation of the idea, not a rewrite |
| **Continue writing** | Picks up where your selection ends |
| **Translate** | Into English, French, Spanish, German, Portuguese, Italian, Turkish, Dutch, Arabic or Romanian |
| **Custom instruction** | Tell the AI what to do, in your own words |

From the review card, choose **Replace selection**, **Insert below**, or **Discard**. Each AI action uses 1 AI usage unit, on every plan.

<Tip>
  **Discuss in Chat** sends the selected passage to [Clamly Chat](/ai/chat) so you can ask follow-up questions about it.
</Tip>

## Turn notes into flashcards

- **Make a flashcard**: select the answer, write the question, pick a deck. Free, and the card is due straight away.
- **Make flashcards**: Clamly AI writes a whole new deck from the note. This uses 4 AI usage units and needs at least a few sentences to work from.

More on how decks are scheduled in [Flashcards](/study/flashcards).

## Organise your notes

- **Pin** the notes you open most so they stay at the top.
- **Drag and drop** to put notes in your own order.
- **Select several** to delete them in one go.
- **Search** from the Notes page, or from anywhere with <kbd>Ctrl</kbd> <kbd>K</kbd>.
- **Add a class** to file a note under a subject. See [Classes](/study/classes).

## Export and share

- **Export as markdown** from the note's menu downloads a `.md` file you can open in any editor.
- **Share with a study group** as read-only, so classmates can read your note but not change it. See [Study groups](/together/groups).

## Delete a note

A deleted note goes to the [Trash](/account/trash). You can restore it for 30 days.
