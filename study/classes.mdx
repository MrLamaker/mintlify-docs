A class is a subject, like Biology or Year 2 Statistics. Give your work a class and you can see one subject at a time instead of everything at once.

## Create a class

1. Open **Classes** and choose **New class**.
2. Name it, pick a colour, and add an emoji if you like.
3. Save.

## Put work in a class

Quizzes, notes, todos, flashcard decks and exams can each belong to one class. Set it when you create the item, or edit the item later.

Then use the **class switcher** to filter a page to one class. Switch back to see everything.

## Archive or delete a class

- **Archive** a class when the term ends. It leaves the switcher, but everything in it stays exactly where it is. Choose **Show archived** on the Classes page to see archived classes and bring one back.
- **Delete** a class to remove it for good. The items in it are not deleted. They become unassigned and show under **No class**.

<Tip>
  Tagging quizzes with a class also unlocks the per-subject table in [Analytics](/progress/analytics).
</Tip>
