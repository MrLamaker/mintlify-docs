Eine Lerngruppe ist ein gemeinsamer Raum für einen Kurs, eine Klasse oder ein paar Freunde. Mitglieder teilen Quizze und Notizen, und ein Aktivitätsverlauf zeigt, was alle gemacht haben.

## Eine Gruppe erstellen

1. Öffne **Study Groups** und wähl **Create Group**.
2. Gib ihr einen Namen und auf Wunsch eine Beschreibung, worum es in der Gruppe geht.
3. Wähl **Create**. Du bist der Eigentümer der Gruppe.

## Leute einladen

Jede Gruppe hat einen Einladungscode. Öffne die Gruppe, nutze **Copy invite code** und schick ihn den Leuten, die dabei sein sollen.

Wenn ein Code irgendwo gelandet ist, wo er nicht hingehört, erzeugt **Regenerate invite code** einen neuen. Der alte Code funktioniert sofort nicht mehr, und wer schon in der Gruppe ist, bleibt drin.

## Einer Gruppe beitreten

1. Öffne **Study Groups**.
2. Füg den erhaltenen Einladungscode in das Feld für den Code ein.
3. Wähl **Join Group**.

## Mit der Gruppe teilen

- **Ein Quiz teilen**, damit alle es spielen können. Es bleibt deins, und die Lösungen werden trotzdem nie an den Browser anderer geschickt.
- **Eine Notiz teilen**, damit alle sie lesen können. Geteilte Notizen sind nur zum Lesen: Mitglieder können damit lernen, aber nur du kannst sie bearbeiten.
- **Save a copy** speichert ein geteiltes Quiz in deinen eigenen Quizzes, wenn der Eigentümer das Kopieren erlaubt hat.

Was du geteilt hast, kannst du jederzeit wieder entfernen. Eigentümer und Admins können alles entfernen, was in der Gruppe geteilt wurde.

<Note>
  Niemand sieht deine Quiz-Ergebnisse, außer du teilst sie.
</Note>

## Rollen

| | Mitglied | Admin | Eigentümer |
| --- | :---: | :---: | :---: |
| Geteilte Quizze spielen und geteilte Notizen lesen | ✓ | ✓ | ✓ |
| Eigene Quizze und Notizen teilen und entfernen | ✓ | ✓ | ✓ |
| Alles entfernen, was in der Gruppe geteilt wurde | | ✓ | ✓ |
| Name und Beschreibung der Gruppe bearbeiten | | ✓ | ✓ |
| Einladungscode neu erzeugen | | ✓ | ✓ |
| Mitglieder entfernen | | Nur Mitglieder | Alle |
| Jemanden zum Admin oder wieder zum Mitglied machen | | | ✓ |
| Mitgliedern erlauben, Kopien geteilter Quizze zu speichern | | | ✓ |
| Die Gruppe löschen | | | ✓ |

Niemand kann die eigene Rolle ändern, und es gibt immer genau einen Eigentümer.

## Eine Gruppe verlassen oder löschen

- **Verlassen** über die Gruppenseite. Du verlierst den Zugriff auf geteilte Quizze und die Aktivität. Was du geteilt hast, bleibt in der Gruppe, bis du oder ein Admin es entfernt.
- **Der Eigentümer kann nicht austreten**, denn sonst hätte die Gruppe niemanden, der sie verwalten kann. Der Eigentümer kann sie stattdessen löschen. Das Löschen einer Gruppe ist endgültig und lässt sich nicht rückgängig machen.

Wenn ein Eigentümer sein Clamly-Konto löscht, werden seine Gruppen mitgelöscht.
